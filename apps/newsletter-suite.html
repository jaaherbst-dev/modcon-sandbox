Newsletter Engine

The editorial suite behind Humanity, Roasted's weekly newsletter — six desks, each with its own AI system prompt and brand voice, plus a Runner to assemble stories into a full edition and a teaser builder for the send.

Archived · Demo Mode Open tool

About this project

This is the actual tool used to write every edition of the Humanity, Roasted newsletter: pick a desk and focus area, generate stories in the brand's voice, tick the ones worth keeping, then run them through the Runner to assemble a full multi-desk edition and build the teaser email.

In production this called a live AI backend. That backend and its API key aren't part of this archive — since the newsletter is no longer live, Generate and Assemble here replay real archived HR output instead of calling an API, so you can see how it worked. The Archive tab holds the genuine history of past editions; anything you generate and save in a session is kept only in your own browser.

The site it once published to is preserved separately: Humanity, Roasted.
